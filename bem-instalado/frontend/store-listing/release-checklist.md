# Checklist de publicação

## Pronto no repositório

- [x] Identificador único: `br.com.instalapro.instaladores`.
- [x] Android com `targetSdk 36`.
- [x] Geração de APK assinado para atualização direta.
- [x] Geração de Android App Bundle (`.aab`) para a Play Store.
- [x] Projeto iOS criado com Capacitor.
- [x] Manifesto de privacidade do iOS com o motivo obrigatório do Preferences.
- [x] Validação iOS automatizada em macOS 26 e Xcode 26.
- [x] Ícones de loja e imagem de destaque.
- [x] Política de Privacidade pública.
- [x] Página pública de exclusão de conta.
- [x] Exclusão definitiva dentro do aplicativo.
- [x] Cancelamento de recorrência antes da exclusão.
- [x] Checkout Asaas mantido no site e removido dos aplicativos das lojas.
- [x] Login com Google oculto no iOS; acesso próprio por e-mail e senha.
- [x] Textos das duas lojas em português.

## Necessário no Google Play Console

- [ ] Criar ou confirmar a conta de desenvolvedor e pagar a taxa do Google.
- [ ] Concluir verificação de identidade e dados de contato.
- [ ] Criar o app com o nome `InstalaPro Instaladores`.
- [ ] Preencher presença na loja, conteúdo do app e Segurança dos dados.
- [ ] Enviar ícone, imagem de destaque e capturas de tela do Android.
- [ ] Criar uma conta de demonstração aprovada e informar acesso ao revisor.
- [ ] Se a conta pessoal for nova, concluir o teste fechado exigido pelo Google.
- [ ] Enviar o `.aab` gerado pelo workflow Android.

## Necessário no Apple Developer e App Store Connect

- [ ] Inscrever-se no Apple Developer Program.
- [ ] Criar o identificador `br.com.instalapro.instaladores`.
- [ ] Criar certificado de distribuição e perfil de provisionamento.
- [ ] Criar o app no App Store Connect.
- [ ] Informar os dados de Privacidade do App.
- [ ] Enviar ícone e capturas de tela do iPhone.
- [ ] Criar uma conta de demonstração aprovada e informar acesso ao revisor.
- [ ] Configurar assinatura no Xcode 26 em um Mac.
- [ ] Gerar o archive, enviar para o TestFlight e concluir o teste interno.
- [ ] Enviar a versão para análise.

## Capturas recomendadas

1. Boas-vindas do aplicativo.
2. Login compacto.
3. Dashboard com indicadores fictícios.
4. Oportunidades da região.
5. Agenda.
6. Criação de orçamento.
7. Perfil profissional.
8. Configurações e tema.

Antes das capturas, usar uma conta fictícia, ocultar dados reais e verificar a
interface em tela pequena e grande.
